# MacroKeypad 사용 설명서

## 주요 기능 및 특징
MacroKeypad는 사용자 정의 가능한 다기능 키패드로, 다음과 같은 주요 기능과 특징을 제공합니다:

- **사용자 정의 키 매핑**: 단일키, 조합키, 매크로를 자유롭게 설정하여 다양한 작업 환경에 맞게 키패드를 구성할 수 있습니다.
- **BLE HID 지원**: 블루투스 HID(Human Interface Device) 모드를 통해 무선으로 PC, 스마트폰 등 다양한 기기와 연결 가능합니다.
- **웹 기반 설정 UI**: GitHub Pages에 호스팅된 직관적인 웹 UI를 통해 키 매핑 및 펌웨어 업로드를 간편하게 수행할 수 있습니다.
- **펌웨어 업그레이드**: USB 연결을 통해 최신 펌웨어를 쉽게 설치하고, 새로운 기능을 추가할 수 있습니다.
- **다중 레이어 지원**: 최대 4개의 레이어를 제공하여 작업 환경에 따라 키 배열을 전환할 수 있습니다.
- **부저 제어**: 볼륨 조절 및 음소거 기능을 통해 알림음을 사용자 환경에 맞게 설정할 수 있습니다.
- **웹 UI 오픈소스**: 웹 UI는 오픈소스로 제공되지만, 키 매핑/펌웨어 업로드와 직접 연관되어 있어 임의 편집은 권장하지 않습니다. 대신 JSON 설정 데이터 수정은 안전하게 활용할 수 있습니다.
- **펌웨어 배포 방식**: 펌웨어는 소스 공개가 아닌 바이너리(배포용) 형태로 제공됩니다.

## 처음 시작하기 (Quick Start)
아래 순서대로 하면 처음 사용하는 분도 바로 사용할 수 있습니다.

1. USB 케이블로 MacroKeypad를 PC에 연결합니다.
2. 웹 UI에 접속합니다: https://3dnote.github.io/macropad/
3. **기기 연결 (CONNECT)** 버튼을 눌러 기기를 연결합니다.
4. 메인 화면 제목 옆에 표시되는 **펌웨어 버전**을 확인하고, 필요 시 **버전 새로고침** 버튼을 눌러 최신 정보를 확인합니다.
5. 키 매핑을 변경한 뒤 **기기에 적용**을 눌러 저장합니다.
6. 블루투스로 사용할 경우, PC/스마트폰의 블루투스 목록에서 "MacroKeypad"를 선택해 연결합니다.

## 준비물 및 권장 환경
- USB 데이터 케이블(충전 전용 케이블은 인식되지 않을 수 있음)
- Chrome 또는 Edge 최신 버전(펌웨어 업로드 및 WebUSB 기능 사용)
- 인터넷 연결(웹 UI 접속용)

## 1. 블루투스 연결 절차
1. 장치를 전원에 연결합니다.
2. 장치가 전원을 받으면 BLE(Bluetooth Low Energy) 모드로 진입합니다.
3. 스마트폰 또는 PC에서 블루투스 설정으로 이동합니다.
4. "MacroKeypad"라는 이름의 장치를 검색하여 선택합니다.
5. 연결이 완료되면 장치가 HID(Human Interface Device)로 동작합니다.

## 2. 웹 UI 연결 방법
1. GitHub Pages에 호스팅된 웹 UI에 접속합니다.
2. 브라우저를 열고 다음 URL을 입력합니다:
   ```
   https://3dnote.github.io/macropad/
   ```
3. 웹 UI가 로드되면 아래 버튼과 기능을 사용하여 설정을 변경할 수 있습니다:
   - **기기 연결 (CONNECT)**: 기기를 연결합니다.
   - **연결 끊기**: 기기와의 연결을 해제합니다.
   - **기기에 적용**: 현재 설정을 기기에 적용합니다.
   - **기본값으로 초기화**: 모든 설정을 초기화합니다.
   - **파일로 저장**: 설정을 JSON 파일로 저장합니다.
   - **파일에서 불러오기**: JSON 파일에서 설정을 불러옵니다.
   - **기기 설정 불러오기**: 기기의 현재 설정을 불러옵니다.
   - **버전 새로고침**: 기기 연결 상태에서 현재 펌웨어 버전을 다시 읽어옵니다.

## 3. 키 매핑 방법
1. 웹 UI에 접속합니다.
2. "키값 리스트"에서 원하는 키를 드래그하여 키 배열에 드롭합니다.
3. "키 편집" 섹션에서 선택된 키의 세부 설정을 변경합니다:
   - **단일키**: 단일 키를 선택하여 매핑합니다. 예: A, Enter.
   - **조합키**: Modifier 키(L-CTRL, L-SHIFT 등)와 일반 키를 조합하여 매핑합니다. 예: CTRL+C.
   - **매크로**: 여러 키 입력을 문자열로 작성하여 매핑합니다. 예: "hello world".
   - **미디어키**: 재생/일시정지, 이전/다음 곡, 음소거, 볼륨 업/다운 등 미디어 키를 매핑합니다.
4. "편집 적용" 버튼을 눌러 설정을 저장합니다.
5. "기기에 적용" 버튼을 눌러 변경 사항을 기기에 반영합니다.

## 4. 펌웨어 업로드 방법
1. USB 케이블로 장치를 PC에 연결합니다.
2. 웹 UI에서 "펌웨어 업로드" 섹션으로 이동합니다.
3. **CONNECT** 버튼을 클릭합니다.
4. 통신 포트를 선택하라는 팝업창이 나타나면, 해당 USB 통신 포트를 선택하고 **연결** 버튼을 클릭합니다.
5. "Connecting..." 메시지가 표시된 후, 펌웨어 업데이트 절차용 "Device Dashboard" 화면이 나타납니다.
6. "Device Dashboard"에서 **Install MacroKeypad**와 **Logs & Console** 메뉴가 표시됩니다.
7. **Install MacroKeypad**를 선택하면, "Confirm Installation" 팝업창이 나타납니다.
   - **Back** 버튼: 이전 화면으로 돌아갑니다.
   - **Install** 버튼: 설치를 진행합니다.
8. **Install** 버튼을 클릭하면 메모리가 지워지고 자동으로 설치가 진행됩니다.
9. "Installation Complete" 메시지가 나타나면 설치가 완료된 것입니다.
10. **Next** 버튼을 클릭하면 다시 "Install MacroKeypad"와 "Logs & Console" 메뉴가 표시됩니다.
11. 이때, 아무 메뉴도 선택하지 않고 팝업창의 **X** 버튼을 클릭하여 창을 닫습니다.
12. 펌웨어 설치가 완료되었습니다.
13. 펌웨어를 새로 설치한 후에는 블루투스 기기를 해제하고 다시 연결해야 합니다.
14. 설치 후 웹 UI 메인 화면에서 **버전 새로고침**을 눌러 정상적으로 업데이트되었는지 확인합니다.

## 5. 펌웨어 관리
MacroKeypad의 펌웨어는 지속적으로 업데이트되며, 최신 버전을 유지하기 위해 다음을 참고하세요:

- **펌웨어 버전 확인**: 웹 UI의 메인 화면 제목 옆에 현재 설치된 펌웨어 버전이 표시됩니다. 기기가 연결된 상태에서 "버전 새로고침" 버튼을 클릭하면 최신 정보를 확인할 수 있습니다.
- **최신 펌웨어 설치**: GitHub Pages를 통해 제공되는 최신 펌웨어를 설치하여 새로운 기능과 버그 수정을 적용하세요.
- **변경 로그 확인**: GitHub 저장소에서 변경 로그(Changelog)를 확인하여 업데이트된 내용을 파악하세요.

## 6. 설정 백업 및 복원
MacroKeypad의 키 매핑 설정은 JSON 파일로 저장 및 복원이 가능합니다. 다음 단계를 참고하세요:

- **설정 백업**: 웹 UI에서 "파일로 저장" 버튼을 클릭하여 현재 설정을 JSON 파일로 저장합니다.
- **설정 복원**: "파일에서 불러오기" 버튼을 클릭하여 저장된 JSON 파일을 불러옵니다.
- **기기 설정 불러오기**: "기기 설정 불러오기" 버튼을 사용하여 현재 기기의 설정을 확인할 수 있습니다.

## 7. 주의 사항
- 펌웨어 업로드 시 올바른 COM 포트를 선택해야 합니다.
- 블루투스 연결 시 다른 장치와의 간섭을 피하기 위해 주변 블루투스 장치를 비활성화하는 것이 좋습니다.
- GitHub Pages에 접속할 때 인터넷 연결 상태를 확인하세요.
- 펌웨어 업로드 시 Chrome 또는 Edge 브라우저를 사용하고, 최신 버전인지 확인하세요.

## 8. 트러블슈팅
### 블루투스 연결 문제
- 장치가 검색되지 않을 경우, 장치를 재부팅하거나 블루투스 설정을 초기화하세요.
- 스마트폰 또는 PC의 블루투스 기능을 껐다가 다시 켜보세요.

### 웹 UI 접속 문제
- GitHub Pages에 접속되지 않을 경우, 인터넷 연결 상태를 확인하세요.
- 브라우저 캐시를 지우고 다시 시도하세요.

### 키 매핑 문제
- 키 매핑이 적용되지 않을 경우, 설정을 다시 저장하고 장치를 재부팅하세요.

### 펌웨어 업로드 문제
- **CONNECT** 버튼이 작동하지 않을 경우, Chrome 또는 Edge 브라우저를 사용하고 최신 버전인지 확인하세요.
- USB 케이블 연결 상태를 확인하고 다시 시도하세요.
- HTTPS로 접속했는지 확인하세요.
